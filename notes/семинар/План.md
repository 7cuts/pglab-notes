### Распределение байтов в `tcp_sendmsg` (kprobe)

**Программка**
```c
kprobe:tcp_sendmsg_locked
{
	@bytes = hist(arg2);
}
```
 arg2 здесь - это размер. Взято из объявления функции: 
```c
int tcp_sendmsg_locked(struct sock *sk, struct msghdr *msg, size_t size)`
```
